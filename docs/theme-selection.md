# 테마 선택 화면

`/admin/theme/select`은 운영자가 저장된 테마와 기본 테마를 미리 보고 적용하는 화면이다.

상단 **테마 → 테마 선택**에서 이동한다. 기존 제작 화면 하단의 테마 관리 목록도 유지하며, 두 화면은 같은 목록과 적용 로직을 사용한다. 선택 화면과 제작 화면을 이동하면 각 화면을 새로 열어 미저장 편집 상태가 섞이지 않게 한다.

- **Tangerine Cream**, **Coastal Sunset**, 저장된 테마를 선택해 미리볼 수 있다.
- 이 화면에서는 테마 생성, 색상 편집, AI 추천, 포스터·홈화면 이미지 변경을 제공하지 않는다.
- 적용은 색상 테마만 변경한다. 홈화면 이미지와 티켓 배경은 유지된다.
- 새 테마를 만들거나 포스터 기반 추천을 사용하려면 `테마 제작·관리 화면으로`를 선택한다.

테마 제작·관리 화면의 **전체 적용**은 선택한 색상 테마와 티켓 배경만 저장한다. 홈화면 이미지는 해당 편집 영역의 **홈화면 이미지 저장**으로 별도 저장하며, 저장하지 않은 홈 이미지 초안은 전체 적용 후에도 유지된다.

2026-10-14 Azure 배포 후 `/admin/theme/select`의 HTTPS 응답과 로그인된 관리자 브라우저의 목록·미리보기를 확인했다. 기존 활성 테마를 보존하기 위해 운영 환경에서는 적용 버튼을 누르지 않았다. 적용 동작은 로컬 회귀 테스트로 검증했다.

## 후속 변경: 제작 화면 기본 펼침 (2026-10-14 Azure 배포)

제작 화면의 `고급 설정`과 그 안의 `브랜드`, `상태`, `지도 카테고리` 색상 그룹은 처음부터 펼쳐진다. 각 제목을 누르면 기존처럼 접거나 다시 펼칠 수 있다. 별도 테마 선택 화면의 기능과 저장·적용 동작은 동일하다.

테마를 새로 만들거나 수정해 저장할 때의 고정 상태색·지도색과 주점/Primary 연동은 [테마 제작 색상 규칙](theme-color-policy.md)을 따른다.

`20261014-theme-policy` 배포 후 관리자 화면을 새로고침하고 고급 설정·브랜드·상태·지도 카테고리가 모두 펼쳐진 상태임을 확인했다. 저장·활성화 요청 없이 기존 테마를 유지했다.
