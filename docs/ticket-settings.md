# 티켓 설정 화면 (DANZ-368)

- `/admin`의 축제 설정과 `/admin/ticketing`의 티켓 설정은 같은 API/회차 ID를 사용한다.
- 티켓팅 메뉴를 누르면 티켓 설정, 팔찌 배부 ↗가 열린다. 팔찌 배부는 `/ticket/admin`으로 이동하며 기존 권한에 따라 로그인 또는 배부 화면으로 연결된다.
- 수정 → 회차별 예매 시각·정원·공연일 선택 → 저장. 공연일은 축제 운영일 목록에서 선택한다. 시작된 회차는 잠겨 있고, 취소하면 저장된 값을 다시 읽는다.
- OFF 배경 설정은 티켓팅 OFF일 때만 표시한다. JPG/PNG 선택 후 미리보기, 저장 시 업로드 및 URL 반영. 기본 안내 화면 사용으로 기존 LEGEND 로고·안내 문구·홈 이동 버튼이 있는 화면을 복원한다. 기본값의 관리자 미리보기도 같은 안내 화면을 사용한다.
- 배경 사진 변경 버튼은 OFF 상태에서 바로 사용할 수 있으며 사진 선택 시 편집 모드로 전환된다. 선택한 사진을 기존 안내 문구·버튼과 함께 미리 보여주고 상단 저장 시 업로드한다. 취소하면 저장된 배경으로 돌아온다.
- 저장 직후 같은 앱의 티켓팅 설정이 갱신된다. 다른 탭은 포커스 복귀 또는 최대 30초 주기 조회로 갱신한다.
- OFF에도 로그인/회원가입/내정보/기존 내 티켓은 이용 가능하다.
- 사용자 예매 목록과 팔찌 배부 목록에 공연일·예매 시작 시각·정원을 구분 표시한다. 예매 시각은 한국 시간 기준이다.

검증: 관련 111개 테스트, 앱/테스트 타입검사, 구조 검사, 빌드·번들 제한 통과. 로컬 브라우저에서 수정/저장/취소, 이미지 파일 선택/저장/조회, 사용자·팔찌 화면의 동일 데이터 표시 확인.
