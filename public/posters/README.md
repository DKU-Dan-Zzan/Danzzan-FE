# 정적 포스터 자산

이 폴더는 시연·디자인 작업에서 수동으로 관리하는 정적 원본을 보관한다. 등록된 공식 포스터, 로고, 홈 배너는 DB 이미지 참조와 Azure Blob 읽기 URL을 사용한다. 다만 등록 이미지가 없거나 불러오지 못한 경우의 기본 포스터와 홈 기본 이미지는 이 폴더의 `legend-poster-홈화면와이드규격.jpeg`를 참조한다. 정적 파일 변경은 기존 DB나 Blob을 수정하지 않지만, 배포 후 해당 기본 이미지 표시에 영향을 줄 수 있다.

2026-10-14 정리에서는 `main-poster-final-vertical.jpeg`를 같은 바이트의 `main-poster-final-vertical-포스터규격.jpeg`로 이름만 바꾸고, 홈 화면용 `legend-home-poster-포스터기본규격.jpeg`를 추가했다. 소스 코드에서 이전·새 파일명을 참조하는 위치는 없음을 확인했다.

정적 자산을 실제 서비스에 쓰려면 관리자 화면을 통해 새 Blob 이미지를 업로드하고 DB 참조를 갱신한다. 기존 Azure 이미지나 게시물의 파일을 직접 덮어쓰지 않는다.

## 추가 이미지 정리 (2026-10-14)

| 파일 | 실제 크기 (가로 × 세로) | 변경 |
| --- | --- | --- |
| `legend-poster-홈화면와이드규격.jpeg` | 923 × 2000 | 기존 `legend-poster-vertical.jpeg`와 바이트가 같은 이름 변경 |
| `낙화유수-홈화면와이드규격.jpeg` | 2457 × 5325 | 새 이미지 추가; 자동 적용되지 않음 |

파일명은 사용자가 지정한 이름을 유지했다. 두 이미지 모두 실제 비율은 세로형이다. 기본 포스터·홈 기본 이미지 코드와 관련 테스트의 참조를 새 파일명으로 바꿨다. JPEG 형식·크기·이름 변경 전후 동일 여부를 확인했으며, 관련 화면 테스트 12건·변경 파일 ESLint·프로덕션 빌드(타입 검사 포함)가 통과했다. 빌드 결과에 두 이미지가 원본 그대로 포함되는 것도 확인했다. 이 커밋 작업에서는 Azure 배포나 DB·Blob 변경을 하지 않았다.
