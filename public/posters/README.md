# 정적 포스터 자산

이 폴더는 시연·디자인 작업에서 수동으로 관리하는 정적 원본을 보관한다. 운영 화면의 공식 포스터, 로고, 홈 배너는 이 파일명을 직접 읽지 않고 DB에 저장된 이미지 참조와 Azure Blob 읽기 URL을 사용한다. 따라서 이 폴더의 파일을 바꿔도 기존 운영 게시물이나 이미지가 자동으로 바뀌지 않는다.

2026-10-14 정리에서는 `main-poster-final-vertical.jpeg`를 같은 바이트의 `main-poster-final-vertical-포스터규격.jpeg`로 이름만 바꾸고, 홈 화면용 `legend-home-poster-포스터기본규격.jpeg`를 추가했다. 소스 코드에서 이전·새 파일명을 참조하는 위치는 없음을 확인했다.

정적 자산을 실제 서비스에 쓰려면 관리자 화면을 통해 새 Blob 이미지를 업로드하고 DB 참조를 갱신한다. 기존 Azure 이미지나 게시물의 파일을 직접 덮어쓰지 않는다.
